ВОЗМОЖНОСТИ · ФАЙЛЫ

Работа с данными на диске

import { readFile } from 'node:fs/promises';

const config = await readFile('config.json', 'utf8');
console.log(JSON.parse(config));

В браузере файл выбирает пользователь; Node.js может обращаться к разрешённым файлам напрямую.

Подключение модулей

// ESM — современный синтаксис

// CommonJS — часто встречается в старом коде

// node: подчёркивает: это встроенный модуль

Префикс node: помогает отличить core-модуль от одноимённого пакета.

03 · PATH

Пути без «магических» строк

path собирает и разбирает пути с учётом Windows, macOS и Linux.

import path from 'node:path';

const file = path.join('uploads', 'avatars', 'ada.png');

path.extname(file); // '.png'
path.basename(file); // 'ada.png'
macOSuploads/avatars/ada.png
Linuxuploads/avatars/ada.png
Windowsuploads\avatars\ada.png

Один и тот же вызов path.join() подставляет разделитель текущей платформы.

PATH · ВАЖНО

join ≠ resolve

path.join('a', 'b')«a/b»склеивает сегменты
path.resolve('a', 'b')«/…/a/b»даёт абсолютный путь

04 · FS

Чтение и запись файлов

import { readFile, writeFile } from 'node:fs/promises';

const text = await readFile('notes.txt', 'utf8');
await writeFile('copy.txt', text.toUpperCase(), 'utf8');

console.log('Готово');

Для нового кода чаще выбирайте node:fs/promises.

FS · АСИНХРОННОСТЬ

Не блокируйте event loop

Избегайте в серверном коде

readFileSync()Останавливает JavaScript-поток на время чтения.

Предпочтительно

await readFile()Позволяет обрабатывать другие задачи во время I/O.

05 · OS И PROCESS

Среда выполнения

import os from 'node:os';

console.log(os.platform());  // 'darwin', 'linux', 'win32'
console.log(os.cpus().length);
console.log(process.cwd());  // текущая рабочая папка
console.log(process.env.PORT ?? 3000);

Переменные окружения — удобное место для конфигурации, но не для секретов в исходном коде.
