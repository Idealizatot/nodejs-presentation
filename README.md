# Node.js core modules — Reveal.js presentation

Интерактивная русскоязычная презентация о базовых встроенных модулях Node.js: `path`, `fs`, `os`, `process`, а также `url`, `crypto`, `events` и `http`.

## Запуск

```bash
npm install
npm start
```

Откройте адрес, который выведет Vite. Для навигации используйте клавиши-стрелки; фрагменты слайдов раскрываются вниз.

## Production-сборка

```bash
npm run build
npm run preview
```

Готовая статическая версия появится в `dist/`.
